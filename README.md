## 🚀 GTA VI Optimization Procedure

### 1. Check System Software

Open:

Settings > System > System Software

Check for updates.

Maintain an updated GTA VI installation.

### 2. Configure Game Presets

Navigate to:

Settings > Saved Data and Game/App Settings > Game Presets

Review the available Performance Mode and Resolution Mode preference.

The game must implement a compatible option for the preference to have an effect.

### 3. Optimize Display Settings

Navigate to:

Settings > Screen and Video > Video Output

Review the available settings.

| Setting | Recommended Action |
|---|---|
| Resolution | Use a compatible display resolution |
| VRR | Enable where supported |
| 120 Hz Output | Enable for supported content |
| HDR | Calibrate for your display |
| ALLM | Use supported low-latency behavior |
| Game Mode | Enable on the television |

### 4. Reduce Processing Delay

On your television or monitor:

1. Select Game Mode.
2. Disable unnecessary motion interpolation.
3. Review image enhancement settings.
4. Check HDMI port compatibility.
5. Verify the selected video output mode.

These steps can reduce additional display processing latency.

### 5. Optimize Remote Play Networking

For streaming sessions:

- Use Ethernet where practical
- Verify sufficient upload bandwidth
- Reduce concurrent network traffic
- Troubleshoot unstable Wi-Fi connections
- Adjust available video quality settings
- Check router configuration when necessary

### 6. Troubleshoot Performance Symptoms

Different symptoms require different solutions.

**Input Delay**

- Check display Game Mode
- Test a direct controller connection
- Compare local gameplay with Remote Play

**Streaming Stutter**

- Check network stability
- Reduce competing traffic
- Test a wired connection

**Image Artifacts**

- Review HDMI configuration
- Check the display signal
- Verify video quality settings

**Unexpected System Issues**

- Install system updates
- Restart the console
- Follow PlayStation support procedures
